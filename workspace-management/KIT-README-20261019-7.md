キットZIPの外部SHA256を照合して新しい場所へ展開し、その場所で実行します。UPDATE_SHA256を同梱更新ZIPの照合値に置き換えてください。

```sh
python apply_catalogue_update.py --base workspace-source-20261011.zip --update catalogue-update-20261019.7.zip --update-sha256 UPDATE_SHA256 --output work/integrated-tools
```


setupは固定版・SHA256を照合して依存を導入します。成果物一覧はcatalog/generated/artifacts.html、製品別予定はcatalog/PORTFOLIO.md、取得元と差分はwork/provenance-20261019/index.htmlで確認できます。ZIP内の成果物一覧48件は作成時の記録で、この候補2件を追加した外部一覧は50件です。

出力回収は一時ログファイルを作らず、stdout/stderrの先頭を各2MiBまで保持します。上限超過後も中断猶予中は読み捨てて監督プロセスの後始末を進めます。超過125、時間切れ124、中断130と部分ログを残します。バイト数は回収した観測値です。対象自身の保存ファイルや管轄外プロセスまで容量・停止を保証するものではありません。

取得元診断は固定基準・指定更新・現在のファイルを照合し、設定に記録された参照先・SHA256・履歴を分けます。GitHubへの通信照合、対象コードの実行、製品E2Eは行いません。

基準ZIPの実内容は20261012.2、互換名はworkspace-source-20261011.zipです。広告フィルターの本文・版・購読URLは変更していません。既存の推奨選択は維持し、今回の候補を自動昇格しません。
