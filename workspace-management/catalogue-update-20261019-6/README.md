# 全成果物・取得元診断・出力回収の更新候補 20261019.6

v8の48ファイル更新です。管理19機能・標準20検査を登録します。本体未取得9製品は含みません。固定基準ZIPの実内容は20261012.2です。

`python tools/manage.py portfolio` で成果物46件（キット作成時）・製品10件・次の開発予定をまとめます。今回の更新とキット自身を含む外部一覧は48件です。固定ZIPの推奨選択は作成時点の情報で、既存の推奨版を自動変更しません。

連続中断が報告処理へ再入しない共有ガードを追加しました。呼出し元の独自SIGINTハンドラーを維持し、終了時に復元します。

新方式の出力回収は一時ログファイルを作らず、stdout/stderrの先頭を各2MiBまで保持します。上限超過後も中断猶予中は読み捨てて監督プロセスの後始末を進めます。バイト数は回収した観測値で、実行対象が書こうとした全量ではありません。所有するPOSIXプロセス群・Windows Jobの停止範囲は従来どおりです。管轄外プロセスや制御側SIGKILLは範囲外です。[方式と制限](catalog/PROCESS-LOGS.md)を参照してください。

[取得元と差分の診断](catalog/SOURCE-PROVENANCE.md)は、指定SHA256の基準ZIPと更新ZIPを検証し、基準・想定・現在のハッシュと設定に記録された参照先をHTML/JSON/Markdownへまとめます。検査対象のコードをimport・実行せず、GitHubとの実内容一致は別途確認が必要です。

新規venvで `tools/manage.py setup`、`doctor`、`all --workflows`、`portfolio`、`check` を実行してください。初回の適用方法は同梱キットのKIT-README.mdを参照します。製品E2E・認証付き動画録画は別途必要です。
