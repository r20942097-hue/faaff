# 全成果物・実行と検証記録の更新候補 20261019.3

v7の43ファイル更新です。19管理機能・20標準検査を登録します。9製品の本体は未取得です。以前の固定ZIPは保持しています。

`python tools/manage.py portfolio`で成果物・次の作業・根拠期限をまとめます。`python tools/manage.py run --tool module-search`は、標準のPython検索先を観測し、対象パッケージのコードをimportしません。実行時importの証明とは区別します。

通常実行と中断猶予付き実行の両方で、stdout/stderrを各2MiBまで保持します。超過・時間切れ・中断では部分ログを残し、所有プロセス群またはWindows Jobを停止します。猶予中は子の監督処理による後始末を待つため一時ファイルへの書込みを継続します。保持量の上限はディスクの瞬間的な容量保証ではありません。

Windowsの起動失敗メッセージに対象実行ファイルを補います。画面検証はPlaywright読込み・ブラウザー起動より前に旧合格を無効化し、起動失敗・検査失敗・中断を記録します。スクリーンショット出力先のシンボリックリンクも拒否します。

生成ルールのURLパスにある改行・制御文字、単独Unicodeサロゲート、メタデータのC1制御文字、255文字を超えるファイル名要素を生成前に拒否します。配信フィルター本文・版・購読URLは変えていません。

新しい場所に展開・適用し、新規venvでsetup、doctor、all、portfolioを実行してください。Windows/Linuxの確認はドラフトPR #16で追跡します。製品E2E・認証付き動画録画は別途必要です。
