# 取得元と更新差分の診断

`source_provenance.py` は固定SHA256の基準ZIPと任意の更新ZIPを検証し、統合ワークスペースの現在のファイルと照合します。GitHub参照、基準・想定・現在のSHA256、ZIPの更新履歴をHTML・JSON・Markdownでまとめます。

この診断は候補20261019.6へ同梱しました。作業ブランチの `workspace-management/` からも実行できます。以前の固定ZIPは保持しています。導入した場合は同梱のcatalog/SOURCE-PROVENANCE.mdを参照してください。

```sh
python workspace-management/source_provenance.py \
  --root /path/to/integrated-workspace \
  --baseline workspace-management/workspace-source-20261011.zip \
  --baseline-sha256 e2ab70a46e41a2f193f8738b0917a9966c3850056f68d79e0f7b48b3e59208d9 \
  --update workspace-management/catalogue-update-20261019.6.zip \
  --update-sha256 856c552178637e07768b54389f7935c2cd24523980a462fadb24b122cb69aea1 \
  --output work/provenance-20261019
```

`--root` は `s/`・`faaff/`・`tools/`・`catalog/config.json` がある**導入済みの統合ワークスペース**です。GitHubのfaaffリポジトリ自体とは異なります。上記のパスは作業場所に合わせて変更してください。Windowsでも同じ引数を1行で指定できます。`--update` と `--update-sha256` の両方を省略すると、基準ZIPだけと比較します。

出力先は検査先の `work/` 以下の新規ディレクトリです。`index.html` をブラウザーで開くと、ファイル名と状態で絞り込めます。既存の出力先への上書きは拒否し、失敗時に完成扱いのレポートを残しません。

| 表示 | 意味 |
|---|---|
| 基準と一致 | 現在と想定版が一致し、基準からも変更されていない |
| 更新版と一致 | 基準から変わり、指定更新を適用した想定版と一致する |
| 想定版から変更 | 現在の内容が基準＋指定更新の想定と異なる。変更の良否は判定しない |
| 現在一覧にない | 想定一覧にはあるが現在一覧にはない。欠落、symlink、設定による選択外を含む |
| 現在のみ存在 | 想定一覧にはないが現在一覧にはある |

固定基準の設定、更新適用後の設定、現在の設定に記録された参照先を区別して表示します。**GitHubへ通信して内容一致を確認する機能ではありません。** ローカルSHA256が一致しても、記録されたGitHub参照先のファイルとの一致まで保証しません。利用者が指定するSHA256自体の出所は、配布記録から別途確認してください。

基準と更新は一時ディレクトリへ検証・展開し、管理側の検証器で更新を適用します。検査先や展開したソースのPythonコードはimport・実行しません。現在の一覧と設定を2回読み、間の変更を検出した場合は停止します。2回の間に変更・復元された操作や全ファイルの同時点スナップショットまでは保証しません。キャッシュ・環境ファイル等は既存カタログの除外規則に従います。

確認例・検証結果は [開発記録](DEVELOPMENT-20261019.md) を参照してください。
